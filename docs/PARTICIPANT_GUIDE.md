# Participant guide: Adaptive Programming Lab

## What you will do

You will learn a little programming with a small app called **Adaptive Programming Lab** and its guide, Nova.
Lessons are short. Plan for **[about 15 minutes, [N] times a week, for [N] weeks]**.

You will:

1. Do lessons. Try each question first. If you get stuck, you can ask Nova for help.
2. Do short **memory checks**. Nova asks again the next day and a week later, with no help. This is how
   we see what really stayed in your memory.
3. Sometimes rate **how sure you are** before an answer. There is no right or wrong rating.

Nova never gives the answer. That is on purpose.

## Getting started

1. Open **your personal link**: [link]. Use the same browser and the same device every time.
2. Read the information page and tick the box if you agree to take part.
3. Choose a nickname (or leave a first name). Your name is not sent to anyone.
4. Pick a course and start with the first lesson.

**Please do not** clear your browser data, use a private (incognito) window, or open the app in a second
browser. Your progress is saved in the browser. If it is cleared, it is lost.

## Every day

- Open the link or the saved app. Press **Memory** if a number shows there: those checks are due.
- Do your lesson. It is fine to stop in the middle. Come back later.
- Please do not search for answers or ask an AI tool during lessons or memory checks. We want to see
  what *you* can do. Using the app's own help is fine.

## Sending your data to the researcher

Nothing is sent automatically. At **[dates]**, and at the end:

1. Open **Settings**.
2. Under **Backup**, press **Download backup**. Keep the file as your own copy.
3. Under **Research and data**, press **Download (JSON)**.
4. Send the JSON file to **[email or upload link]**. The file has a code (for example `L-7KQ2MD`)
   and your participant code, not your name. It also includes the sentences you write when Nova asks you to
   explain a hint, so please do not write personal details there.

## If something goes wrong

| Problem | What to do |
|---|---|
| The page does not open | Check the internet. The first lesson in each course needs it to load the code tools. After that, lessons can work offline. |
| A code lesson says it could not run | Wait a moment and try again, or press skip and tell **[contact]**. |
| You lost your progress | Tell **[contact]**. If you have a backup, Settings > Backup > Restore from file. |
| You want to stop | You can stop at any time without giving a reason. Tell **[contact]**, and use Settings > Delete this learner to remove everything on your device. |
